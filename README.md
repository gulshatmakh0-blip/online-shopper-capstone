# Посещения интернет-магазина и покупки

Индивидуальный учебный capstone. Задача: выделить покупателей среди 20% завершённых посещений с самой высокой оценкой модели. Открытые данные не относятся к конкретному магазину автора.

## Быстрый запуск в Visual Studio / VS Code

Откройте эту папку как проект. В терминале редактора выполните:

```powershell
python -m pip install -r requirements.txt
python train.py
python -m streamlit run app.py
```

Обучение занимает несколько минут. Датасет уже включён, скачивать его повторно не требуется. Для ноутбука выберите тот же Python и откройте `analysis.ipynb`. При необходимости установите ядро: `python -m pip install ipykernel`. Выполняйте ячейки сверху вниз.

Если `python` не найден, попробуйте `py` вместо `python`. Если версии библиотек отличаются от сохранённой модели, сначала заново выполните `train.py`.

## Файлы

- `analysis.ipynb`: анализ и объяснения шагов.
- `train.py`: основной код подготовки данных, настройки и оценки моделей.
- `app.py`: приложение для Demo Day.
- `data/online_shoppers_intention.csv`: исходные данные без изменений.
- `data/demo_sessions.csv`: примеры входных данных из отложенного теста, без целевого признака.
- `results/`: модель, метрики и графики, воспроизводимые командой `python train.py`.
- `REPORT.md`: постановка задачи, методология, результаты и ограничения.
- `DEMO.md`: сценарий выступления и ответы на вопросы.

## Методология

Удаляем полные дубли до разделения. Исключаем `PageValues`, поскольку показатель связан с ценностью страниц относительно транзакций и момент его расчёта неизвестен. `Revenue` используется только как целевая переменная. Категориальные коды региона, браузера, ОС и источника трафика не интерпретируем как числовой порядок.

Стратифицированное разделение 80/20, random_state=42. Обработка признаков и подбор параметров выполняются внутри Pipeline и 3-fold cross-validation только на train. Выбор модели по average precision на CV. Финальный тест используется для оценки и никогда для подбора параметров. PR-AUC в проекте обозначает average precision, а не трапецеидальную площадь.

Числа можно обновить повторным запуском. При пороге 0.5 recall низкий, поэтому основная бизнес-задача проекта связана с ранжированием. Оценки модели отдельно не откалиброваны.

## GitHub и развёртывание

Создайте репозиторий и загрузите содержимое этой папки. Не загружайте `work`, временные окружения и локальные библиотеки. Папку `results` можно включить: её содержимое получено из открытого датасета. Для Streamlit Community Cloud выберите репозиторий и главный файл `app.py`; используйте Python 3.14 с указанными версиями. Если облачный сервис не поддерживает эту версию, используйте совместимые версии библиотек и заново обучите модель. Локальный запуск уже позволяет провести демонстрацию. Репозиторий: https://github.com/gulshatmakh0-blip/online-shopper-capstone. Приложение проверено локально; отдельное облачное развёртывание пока не выполнено.
